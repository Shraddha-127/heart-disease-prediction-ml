# Heart Disease Prediction Using Machine Learning

A machine-learning-based web application that predicts the likelihood of heart disease based on patient health parameters. The system combines a Random Forest machine-learning model, SHAP-based explainable AI, a Flask web application, SQLite database, PDF report generation, and an AI-powered health chatbot using Ollama and Llama 3.

> Disclaimer: This project is developed for educational and demonstration purposes only. It is not a medical diagnostic tool and should not replace professional medical advice.

## Project Overview

The Heart Disease Prediction System is an interactive web application that uses machine learning to predict the likelihood of heart disease based on selected health parameters.

Users can register and log in to the application, enter health-related information, receive a prediction with a confidence score and risk level, view the important factors contributing to the prediction, download a PDF report, and access their previous prediction history.

The application also includes an AI-powered health chatbot integrated with Llama 3 through Ollama, which provides general educational information related to heart health and helps explain prediction results.

## Machine Learning Model

The application uses a Random Forest Classifier for heart disease prediction.

### Model Configuration

- Algorithm: Random Forest Classifier
- Number of estimators: 200
- Random state: 42
- Feature scaling: StandardScaler
- Explainability: SHAP TreeExplainer

### Model Performance

The model achieved an accuracy of approximately 92.19% on the evaluated dataset.

The application also provides a confidence score for each prediction based on the probability generated by the trained classification model.

## Input Features

The prediction model uses the following 13 health-related parameters:

1. Age
2. Sex
3. Chest Pain Type
4. Resting Blood Pressure
5. Cholesterol
6. Fasting Blood Sugar
7. Resting ECG
8. Maximum Heart Rate
9. Exercise-Induced Angina
10. Oldpeak
11. ST Slope
12. Number of Major Vessels (CA)
13. Thalassemia (Thal)

## Explainable AI Using SHAP

The system uses SHAP (SHapley Additive exPlanations) to make the machine-learning predictions easier to understand.

After generating a prediction, SHAP values are calculated for the input data. The application identifies the most influential features and displays the top contributing factors.

This helps users understand which input parameters had a greater influence on the model's prediction.

## Installation

### 1. Clone the repository

git clone https://github.com/Shraddha-127/heart-disease-prediction-ml.git

### 2. Navigate to the project directory

cd heart-disease-prediction-ml/Heart_Disease_Prediction

### 3. Create a virtual environment

python -m venv venv

### 4. Activate the virtual environment

For Windows:

venv\Scripts\activate

### 5. Install the required dependencies

pip install -r requirements.txt

## Ollama Setup

The AI chatbot uses a locally running Ollama server with the Llama 3 model.

Install Ollama and download the Llama 3 model:

ollama pull llama3

Start the Ollama server:

ollama serve

Verify that the model is available:

ollama list

## Running the Application

Navigate to the Heart_Disease_Prediction directory and run:

python app.py

The Flask application will start on the local server.

Open the local URL displayed in the terminal in your web browser.
